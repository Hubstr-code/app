# Use Hubstr on Slack

Slack works in two phases: a **workspace admin installs** the official Hubstr Slack app once, and then **each member links** their personal Hubstr account. Both phases happen from **Settings → Messenger → Slack**.

## Prerequisites

- A Hubstr account
- A Slack workspace
- For the install step: permission to install Slack apps in that workspace (typically Workspace Admin or a permission granted by one)

## Phase A — Install the Hubstr Slack app (admin, once per workspace)

<Steps>
  ### Open Settings → Messenger → Slack

  In Hubstr, open **Settings → Messenger** and click the **Slack** card. Click **Connect** in the top-right.

  {/* TODO: screenshot — Slack detail page with empty Connections list and the Connect button */}

  ### Authorise on Slack

  You'll be redirected to Slack's authorisation screen. Pick the workspace you want to install into and click **Allow**.

  {/* TODO: screenshot — Slack OAuth consent screen */}

  ### Workspace appears under Connections

  After approval you're redirected back to Hubstr. The workspace shows up as a **workspace** row in **Connections**, with a status of **Connected**.

  {/* TODO: screenshot — Slack detail page showing one connected workspace row */}

  > **Workspace already connected by someone else?** Hubstr blocks the install and shows a "Workspace already connected" notice. You don't need to install again — just DM **@Hubstr** on Slack to link your personal account. If you want to take over ownership, ask the original installer to disconnect the workspace first.
</Steps>

## Phase B — Link your personal account (each member)

<Steps>
  ### Open the Hubstr bot on Slack

  On Slack, open the **Apps** sidebar and find **Hubstr**, or search for `@Hubstr`. Open a DM with the bot.

  {/* TODO: screenshot — Slack apps sidebar with Hubstr highlighted */}

  ### Send any message

  Send any message to the bot to trigger the linking flow. The bot replies with a one-time confirmation link.

  {/* TODO: screenshot — Slack DM showing the bot's "Link Account" reply */}

  ### Confirm the link in your browser

  Tap the link, sign in to Hubstr if asked, and choose a **default agent**. Every message you DM the bot in this workspace will route to this agent.

  {/* TODO: screenshot — confirm-link page in Hubstr with the agent picker */}

  Your link appears as a **user** row under the workspace install in **Connections**.

</Steps>

## Switching the Active Agent

Two equivalent ways:

- **On Slack** — DM the bot `/agents` and pick a different agent.
- **In Hubstr** — open **Settings → Messenger → Slack** and use the agent picker on your link row.

The change takes effect on the next message you send.

## Disconnecting

Slack has two distinct disconnect actions:

| Action                              | Effect                                                                                                                                                                                                  |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Disconnect** on a *user* row      | Unlinks **your** Hubstr account from your Slack account in this workspace. Your inbound DMs stop until you message the bot and link again.                                                             |
| **Disconnect** on a *workspace* row | Removes the workspace install. The bot is **frozen for everyone** in that workspace because dispatch is token-gated — existing user links remain on file but pause until the workspace is re-installed. |

You can re-install (workspace) or re-link (personal) at any time by repeating the relevant phase.

## Troubleshooting

- **"Workspace already connected"** — Another Hubstr user already installed the app to this workspace. DM **@Hubstr** to link your personal account; you do not need to install again. To take over ownership, ask the original installer to disconnect first.
- **Slack install failed (`<reason>`)** — Common reasons: authorisation cancelled, install session expired (re-open the modal and try again), Slack returned incomplete data (retry; if persistent, contact support).
- **Bot does not reply to your DM** — The workspace install may have been disconnected. Check **Settings → Messenger → Slack** for a workspace row; if missing, ask an admin to re-install.
- **"This link is already used"** — One-time confirmation links expire after one use. DM the bot again to get a new link.
- **"This account is already linked"** — Your Slack account is bound to a different Hubstr account. Sign in to that Hubstr account to manage the link, or unlink there before retrying.
- **"Another Slack account is already linked"** — Your Hubstr account already has a Slack link in this workspace. Disconnect it in **Settings → Messenger → Slack** before linking a new Slack account.
